# I miei turni — progetto Android

App Android semplice con WebView e calendario turni lunedì-domenica.

## Generare l'APK
1. Installa Android Studio sul computer.
2. Apri Android Studio e scegli **Open**.
3. Seleziona questa cartella `TurniAndroidProject`.
4. Attendi la sincronizzazione Gradle e l'installazione dei componenti Android richiesti.
5. Dal menu **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. Android Studio mostrerà un collegamento al file APK generato, di solito in `app/build/outputs/apk/debug/app-debug.apk`.
7. Copia l'APK sul telefono e aprilo per installarlo. Potrebbe essere necessario consentire l'installazione da quella sorgente.

Settimana: lunedì-domenica. Modifica tipo di turno, orari e note; i dati sono conservati localmente nell'app.

Nota: in questo ambiente non è disponibile l'SDK Android/Gradle per compilare e verificare direttamente un APK. Questo è il progetto sorgente pronto da aprire in Android Studio, non un APK già compilato.
